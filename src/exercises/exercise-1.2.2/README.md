# exercise-1.2.2 - Master-Detail View

## Description
CSS Grid, useParams, people.find and 404 handling.
The list and detail use two columns above 700px and stack at 700px and below.
Use `/people` for the list, `/people/1` for a valid detail, and `/people/999` for the person 404 state.

## Source Files
src/pages/People.jsx, src/pages/PersonDetail.jsx, src/data/people.js, src/App.css

## Project
Lab 4 - Multi-Route SPA Architecture

## How to Run
1. Run npm install in the project root.
2. Run npm run dev.
3. Open the local URL shown in the terminal.
4. Select the corresponding Exercise on the Home page.
